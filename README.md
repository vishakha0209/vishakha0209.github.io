# Vishakha Garg | Data Engineer Portfolio

**Live site:** [vishakha0209.github.io](https://vishakha0209.github.io)

An animated, self-playing portfolio. My photo sits at a desk while eight short scenes pop in one by one, like a reel, so visitors don't need to scroll.

I'm a Tech Lead in data engineering with 8+ years of experience in ETL, data warehousing and data quality. I'm now building on Databricks, Azure and AI agents.

Visitors can pause, skip between scenes, or turn on the background music.

## Built with

- **HTML and CSS:** layout, dark cinematic theme, glow and glitch effects
- **JavaScript with [GSAP](https://gsap.com):** the auto-playing animation timeline
- **HTML Canvas:** the flowing data streaks in the background
- **Web Audio API:** an original soundtrack and scene transition sounds, generated in code with no audio files
- **Python with OpenCV:** photo cropping and blending into the page

It's a single `index.html` with no build step and no server, hosted free on GitHub Pages.
